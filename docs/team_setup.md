# Setting up a team member's computer

Each person runs the reports **on their own Windows computer**. Reports, the run history and the Google sign-in are kept on that computer only. This guide takes
about 20 minutes the first time.

## What you need before you start
* The project folder (from the team lead: a copy or a Git clone). A folder such as `C:\JasperSEO` is best; a OneDrive folder works but is slower.
* **Python 3.14** from python.org (tick the `py` launcher).
* From the team lead, through a private channel (a password manager, never e-mail or chat):
  * the **OAuth client file** (a small `.json` file),
  * the **reporting workbook's address** (the Google Sheet),
  * `config\clients.yaml` (so everyone uses the same client keys; copy it into the project's `config` folder).
* The shared **Google account** that can open the clients' Search Console and GA4 properties.

## Steps (in a normal PowerShell window, in the project folder)

| # | Command / action | What it does |
|---|---|---|
| 1 | `.\scripts\install_device.ps1` | Creates the private Python environment, installs the tested packages, downloads the PDF browser. |
| 2 | `.\seo.cmd setup device --spreadsheet-id "<workbook address>"` | Creates your per-user folders, installs the report fonts (verified), writes your settings file, locks the credentials folder to your account, and **lists what is still missing**. |
| 3 | Save the OAuth client file as the path step 2 printed (`...\credentials\client.json`) | Never put it in the project folder. |
| 4 | `.\seo.cmd setup auth` | Opens a browser. Sign in with the team's Google account and allow access. |
| 5 | `.\seo.cmd setup device` | Run again: every line should now say `ok`. |
| 6 | `.\seo.cmd doctor` | The full check (Python, packages, browser, fonts, storage). |
| 7 | `.\seo.cmd web` | Opens the page. Press **Refresh from the sheet**. |

If `config\clients.yaml` was not copied, after step 4 run `.\seo.cmd clients add --all-missing --yes` to build it from the sheet. Keys made this way match the lead's
only when the names are written the same, so copying the lead's file is better.

## Every day
1. `.\seo.cmd web`, then **Refresh from the sheet**.
2. Click **Verify and run** (or **Run report**) on a client, or **Run all that are ready**.
3. **Open PDF** when it shows Done.

If a step says Google sign-in has expired, run `.\seo.cmd setup auth` once, then Refresh.

## Things that are the same for everyone
* A finished report is never overwritten. A "new" report means a new 28-day period in the sheet.
* Verification (`verify live`) lasts 7 days and is tied to your Windows account and this computer; it is done for you by **Verify and run**.
* Two people can create the same client's report on their own computers without knowing. Agree who runs which clients.

## If something goes wrong
* `.\seo.cmd setup device` shows each problem with the exact fix.
* `.\seo.cmd doctor` gives the full technical check.
* Errors from every command explain **what it means** and **what to do**.

## Security rules
* The OAuth client file and your sign-in file stay in `%LOCALAPPDATA%\JasperSEOReporting\credentials`. Never copy them into the project, a chat, an e-mail or Git.
* Never share the page's address (it contains a one-time access token and only works on your computer).

## Seeing what teammates have already generated (optional)
Reports stay on the computer that made them. To see, before you run a client, that someone else already did, the team can share one folder (a synchronised or network
folder that everyone can write to). Each person sets it once on their computer:

```
.\seo.cmd setup device --shared-folder "D:\TeamShare\seo-activity"
```
(on a computer that is already set up, add `shared_activity_dir: "D:\\TeamShare\\seo-activity"` under `paths:` in `%LOCALAPPDATA%\JasperSEOReporting\config\runner.yaml`).
After that, the web page and `seo clients check` warn "Already generated by <name> on another computer". Only a small line per finished report is shared (client key, period,
the person's Windows account name, the computer name, the time); nothing else. If you use a shared Windows account, set `JASPER_SEO_OPERATOR` to your own name so your reports
are attributed to you.
