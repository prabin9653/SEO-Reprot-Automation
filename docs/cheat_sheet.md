# Cheat sheet: creating SEO reports

Open a normal PowerShell window in the project folder.

## Every day
```
.\seo.cmd web
```
1. Open the address it prints (it contains a one-time token; do not share it).
2. Press **Refresh from the sheet**.
3. On a client that is **Ready** and **Not run**, click **Verify and run** (or **Run report**) and confirm.
4. Wait for the job panel to show a tick on every step. The row turns **Done**.
5. Click **Open PDF**.

**Run all that are ready** does steps 3 to 4 for every Ready client, one after another.

## What the row colours mean
| Shown | Meaning | What to do |
|---|---|---|
| Ready, Not run | everything in the sheet is fine | Run it |
| Ready, **Done** | a report for these dates exists on this computer | Open PDF. For a new report, change the dates in the sheet |
| Ready, Failed last time / Interrupted | a run did not finish | Retry |
| Needs fix | something in the sheet is wrong | the row says exactly what, fix it in the sheet, then Refresh |
| Not registered | the client is in the sheet but has no key here | Register |
| Skipped | Status in the sheet is not Active | set it to Active if it should run |
| "Already generated by ... on another computer" | a teammate already made this report | decide whether a second copy is needed |

## Making a new report for a client who is already Done
1. In the Google Sheet, set the client's **Report Start Date** and **Report End Date** to a new period of **exactly 28 days** (for example 2026-10-29 to 2026-11-25).
2. Press **Refresh from the sheet**, then **Run report**.

## When something fails
Every message says **what it means** and **what to do**. The usual ones:
* *Google sign-in expired / revoked* → in PowerShell: `.\seo.cmd setup auth`, then Refresh. (About weekly while the Google consent screen is in Testing mode.)
* *Search Console property not accessible* → the property in the sheet must match Search Console exactly (www or not, http or https, trailing slash, or `sc-domain:`) and the signed-in account needs access.
* *Verification expired* → Verify and run does it for you.
* *Period differs from the sheet* → use the sheet's exact dates.

## Console equivalents
```
.\seo.cmd clients check                       # one table: ready, or exactly what to fix
.\seo.cmd verify live --client KEY --live     # Google check, valid 7 days
.\seo.cmd report run --client KEY --period START_END --production
.\seo.cmd report open --client KEY
.\seo.cmd doctor                              # full technical check of this computer
```

## Rules to remember
* A finished report is never overwritten or deleted.
* Reports live on the computer that made them. Share finished PDFs yourselves (a shared folder).
* Never put the Google credential files in the project, e-mail or chat.
